## Overview

Electron PC is a free Windows utility that requires no key and provides a simplified way to execute Lua scripts in Roblox. It is intended for users who want to work with custom scripts without navigating a lengthy setup process. The application connects to Roblox through a streamlined injection workflow and runs Lua code supplied by the user.

A categorized hub brings together more than 500 scripts submitted by the community, including automation utilities and visual tools. Automatic updating is included, while the application maintains a footprint under 10 MB for a lightweight experience on current Windows systems.

## Frequently Asked Questions

**Is Electron PC safe to use?**

Electron PC runs Lua scripts provided by the user inside Roblox. You should decide whether to use it and only execute scripts you trust. The application itself does not contain malicious code.

**Does it support the newest Roblox release?**

The updater is intended to maintain compatibility with the current Roblox version. When a Roblox update disrupts injection, a patch is generally issued within 24 hours.

**What sets Electron PC apart from other executors?**

The project emphasizes a small footprint, free access, and the absence of a key system. It also combines a sizable script hub with batch execution capabilities that may not be available in many comparable tools.

**Could using it result in a Roblox account ban?**

Third-party execution tools are against Roblox's Terms of Service, so account action is always possible. If that risk is a concern, use the tool responsibly with alternate accounts.

**Where does Electron PC keep my scripts?**

Scripts added by the user are saved locally in `Scripts/Local/`. Hub content is downloaded during the first launch and cached so it can be used offline.
